# ÜB8 student environment

Start:
    sudo python3 start_lab.py

Useful:
    ip -br addr
    ip route
    ping -c 3 10.0.2.2
    traceroute 10.0.2.2
    ./capture.sh eth0 /tmp/ub8.pcap

The topology is deliberately more complex than ÜB6/ÜB7 and contains two possible paths.
Students should use the assignment instructions to inspect and modify routing.
